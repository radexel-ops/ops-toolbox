# 01. Vision & Goals - VibeOps

> **문서 목적**: 프로젝트의 비전, 목표, 기대효과를 정의합니다.

---

## 1. 프로젝트 배경

### 1.1 현재 상황 (As-Is)
- 경영기획팀의 자동화 작업이 개발팀에 의존
- 자동화 스크립트가 로컬 PC에 분산되어 관리 어려움
- 새로운 자동화 요청마다 개발 리소스 필요

### 1.2 문제점
| 문제 | 영향 |
|------|------|
| 개발팀 의존성 | 자동화 요청 대기 시간 증가 |
| 로컬 PC 실행 | 24시간 자동화 불가, PC 고장 시 중단 |
| 분산 관리 | 버전 관리 어려움, 중복 개발 |
| 확장성 부재 | 새 기능 추가 시 처음부터 개발 |

---

## 2. 비전 (Vision)

### "경영기획팀이 직접 만들고 운영하는 AI 자동화 플랫폼"

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   "웹에서 말하면, AI가 움직인다"                              │
│                                                             │
│   사용자: "이번 주 야근자 명단 뽑아서 표로 보여줘"            │
│                     ↓                                       │
│   AI: [데이터 조회] → [표 생성] → [결과 표시]                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

---

## 3. 목표 (Goals)

### 3.1 단기 목표 (3개월)
1. **클라우드 이관**: 로컬 자동화 스크립트를 DigitalOcean 서버로 이관
2. **24시간 운영**: 서버에서 자동화 스크립트 상시 가동
3. **웹 대시보드**: 기본적인 모니터링 및 제어 인터페이스

### 3.2 중기 목표 (6개월)
1. **대화형 개발**: 웹에서 Claude Code와 대화하며 새 기능 개발
2. **에이전트 확장**: 더존, 뉴스 외 추가 자동화 에이전트
3. **팀 확장**: 경영기획팀 전원 사용 가능

### 3.3 장기 목표 (1년)
1. **1인 1 AI**: 전 임직원에게 개인 AI 에이전트 제공
2. **자율 학습**: 반복 업무 패턴을 학습하여 선제적 제안
3. **사내 표준화**: 전사 업무 자동화 플랫폼으로 확장

## 4. 핵심 기능 (Core Features)

### 4.1 대화형 브릿지 시스템
| 기능 | 설명 |
|------|------|
| 웹 채팅 | 자연어로 명령 입력 |
| 실시간 연결 | 웹 ↔ 서버 터미널 직접 연결 |
| 결과 스트리밍 | 작업 진행/완료 실시간 표시 |

### 4.2 자동화 에이전트
| 에이전트 | 기능 |
|----------|------|
| 더존 에이전트 | 휴가/근태 자동 추출, 캘린더 동기화 |
| 뉴스 에이전트 | 키워드 뉴스 스크래핑, 슬랙 전송 |
| (확장) | 회계, 인사, 계약 관리 등 |

### 4.3 Tmux 기반 팀메이트
- 여러 AI 에이전트가 병렬로 작업
- PM 에이전트가 작업 분배
- 에이전트 간 협업 가능

---

## 5. 기대 효과

### 5.1 정량적 효과
| 지표 | 현재 | 목표 |
|------|------|------|
| 자동화 요청 대기시간 | 1-2주 | 즉시 (대화로 해결) |
| 24시간 자동화 | 불가 | 가능 |
| 신규 자동화 개발 | 개발팀 의뢰 | 직접 대화로 생성 |

### 5.2 정성적 효과
- **자율성 확보**: 경영기획팀의 기술 자립
- **빠른 반복**: 아이디어 → 구현 사이클 단축
- **지식 축적**: 자동화 노하우가 시스템에 축적

## 6. 성공 기준 (Success Criteria)

### Phase 1 완료 기준
- [ ] 서버에서 기존 자동화 스크립트 정상 동작
- [ ] 웹에서 스크립트 실행/중지 가능
- [ ] 기본 로그 모니터링 가능

### Phase 2 완료 기준
- [ ] 웹 채팅으로 Claude Code와 대화 가능
- [ ] 대화로 간단한 데이터 조회 가능
- [ ] 새로운 자동화 요청을 대화로 처리

### Phase 3 완료 기준
- [ ] 3개 이상의 에이전트 안정 운영
- [ ] 경영기획팀 전원 사용 중
- [ ] 주간 자동화 보고서 자동 생성
