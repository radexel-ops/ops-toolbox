## 2. 관리자 대시보드 구현

### 2.1 구현할 탭 (4개)

| 탭 | 영문명 | 기능 |
|---|--------|------|
| 승인대기 | Pending Users | 가입 승인 대기 사용자 관리 |
| 사용자 관리 | Users | 전체 사용자 CRUD, 권한 관리 |
| 피드백 | Feedback | 사용자 피드백 수집/관리 |
| 클로드 브릿지 | Claude Bridge | Claude Code CLI 인터페이스 |

### 2.2 제외할 탭

- 개요 (Overview)
- 크레딧 관리 (Credits)
- 행동 분석 (Analytics)

## 3. 컴포넌트별 상세 설계

### 3.1 승인대기 탭 (PendingUsersTab)

**기능**:
- 승인 대기 사용자 목록 표시
- 사용자 카드 형태 (아바타, 이메일, 회사명, 요청일)
- 승인/거절 버튼
- 빈 상태 메시지

**UI 패턴**:
```
┌─────────────────────────────────────────┐
│ 승인대기 (3)                            │
├─────────────────────────────────────────┤
│ ┌─────────────────────────────────────┐ │
│ │ [Avatar] user@example.com          │ │
│ │          Radexel Inc. · 2026-02-10 │ │
│ │          [승인] [거절]              │ │
│ └─────────────────────────────────────┘ │
│ ┌─────────────────────────────────────┐ │
│ │ [Avatar] user2@example.com         │ │
│ │          ...                        │ │
│ └─────────────────────────────────────┘ │
└─────────────────────────────────────────┘
```

### 3.2 사용자 관리 탭 (UsersTab)

**기능**:
- 검색 (이메일, 이름)
- 필터 (역할, 상태, 팀)
- 정렬 (이름, 가입일, 마지막 로그인)
- 테이블 형식 목록
- 사용자 상세/편집 모달
- 역할 변경, 활성화/비활성화

**UI 패턴**:
```
┌─────────────────────────────────────────────────┐
│ 사용자 관리                                      │
├─────────────────────────────────────────────────┤
│ [🔍 검색...    ] [역할 ▼] [상태 ▼] [팀 ▼]       │
├─────────────────────────────────────────────────┤
│ 이름          이메일           역할    상태  액션 │
│ ───────────────────────────────────────────────│
│ 홍길동        hong@...         관리자  활성  [⋮] │
│ 김철수        kim@...          팀원    활성  [⋮] │
│ 이영희        lee@...          팀원    비활성 [⋮] │
└─────────────────────────────────────────────────┘
```

### 3.3 피드백 탭 (FeedbackTab)

**기능**:
- 피드백 목록 (아코디언 형태)
- 상태 관리 (신규, 검토중, 해결됨)
- 대량 작업 (선택 삭제, 상태 변경)
- 브릿지 연동 버튼 (해당 피드백을 Claude에게 전달)

**UI 패턴**:
```
┌─────────────────────────────────────────────────┐
│ 피드백 관리                      [대량 작업 ▼]   │
├─────────────────────────────────────────────────┤
│ ┌─────────────────────────────────────────────┐ │
│ │ [☐] [🟢 신규] "로그인이 느려요"              │ │
│ │     user@example.com · 2026-02-10           │ │
│ │     ────────────────────────────────────────│ │
│ │     상세 내용이 여기에 표시됩니다...          │ │
│ │     [상태변경 ▼] [브릿지로 전송] [삭제]      │ │
│ └─────────────────────────────────────────────┘ │
│ ┌─────────────────────────────────────────────┐ │
│ │ [☐] [🟡 검토중] "새 기능 제안"              │ │
│ │     ...                                     │ │
│ └─────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────┘
```

### 3.4 클로드 브릿지 탭 (ClaudeBridgeTab)

**기능**:
- Claude Code CLI 채팅 인터페이스
- 명령어 히스토리
- 실시간 응답 스트리밍
- 상태 표시 (연결됨/연결 안됨/처리중)
- 팀 컨텍스트 정보 표시

**UI 패턴**:
```
┌─────────────────────────────────────────────────┐
│ Claude Code Bridge            [🟢 연결됨]        │
├─────────────────────────────────────────────────┤
│ ┌─────────────────────────────────────────────┐ │
│ │ 컨텍스트: Default Team · super_admin        │ │
│ └─────────────────────────────────────────────┘ │
│                                                 │
│ ┌─────────────────────────────────────────────┐ │
│ │ [메시지 영역]                               │ │
│ │                                             │ │
│ │ User: 안녕하세요                            │ │
│ │                                             │ │
│ │ Claude: 안녕하세요! VibeOps에 오신 것을     │ │
│ │ 환영합니다...                               │ │
│ │                                             │ │
│ └─────────────────────────────────────────────┘ │
│                                                 │
│ ┌─────────────────────────────────────────────┐ │
│ │ [메시지 입력...                    ] [전송] │ │
│ └─────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────┘
```

## 4. 파일 구조

### 4.1 수정할 파일

```
frontend/
├── css/
│   ├── variables.css      # 디자인 토큰 업데이트
│   ├── main.css           # 기존 스타일 업데이트
│   └── admin.css          # 새로 생성 - 관리자 대시보드 스타일
├── js/
│   ├── main.js            # 네비게이션 업데이트
│   └── admin.js           # 새로 생성 - 관리자 기능
├── index.html             # 메인 페이지 업데이트
└── admin.html             # 새로 생성 - 관리자 대시보드
```

### 4.2 백엔드 API 추가

```
backend/app/routers/
├── admin.py               # 새로 생성 - 관리자 API
└── feedback.py            # 새로 생성 - 피드백 API
```

## 5. 구현 순서

### Phase 1: 디자인 시스템 적용
1. `variables.css` 업데이트 - 새 디자인 토큰 적용
2. `main.css` 업데이트 - 전체 스타일 개선

### Phase 2: 관리자 대시보드 구조
1. `admin.html` 생성 - 탭 기반 레이아웃
2. `admin.css` 생성 - 관리자 전용 스타일
3. `admin.js` 생성 - 탭 전환, API 호출 로직

### Phase 3: 백엔드 API
1. 사용자 관리 API (승인/거절/수정)
2. 피드백 API (CRUD)
3. 기존 브릿지 API 활용

### Phase 4: 각 탭 구현
1. 승인대기 탭
2. 사용자 관리 탭
3. 피드백 탭
4. 클로드 브릿지 탭 (기존 채팅 기능 이식)

### Phase 5: 테스트 및 배포
1. 로컬 테스트
2. 서버 배포
3. 기능 검증
