# AI Infinite Chat 종합 점검 계획서

## 시스템 구조
```
┌─────────────────────────────────────────────────────────────┐
│                    Docker Compose                            │
│  ┌─────────────────┐    ┌─────────────────────────────────┐ │
│  │    Frontend     │    │           Backend               │ │
│  │   (Nginx:80)    │◄──►│         (FastAPI:8000)          │ │
│  │                 │    │                                 │ │
│  │  - React SPA    │    │  - REST API (/api/*)           │ │
│  │  - WebSocket    │    │  - WebSocket (/ws/chat)        │ │
│  │  - IndexedDB    │    │  - AI Providers (OpenAI/Gemini)│ │
│  └─────────────────┘    └─────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

4. **Docker logs** - 컨테이너 로그 분석
5. **Browser DevTools** - 프론트엔드 디버깅
