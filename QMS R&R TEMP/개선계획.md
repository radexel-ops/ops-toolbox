# QMS R&R AI 분류 스크립트 개선 계획

## 1. 현재 문제점 분석

### 1.1 결과물 문제점
```
현재 담당자별 배정 현황 (36건 기준):
  - 이선희 (수민L): 12건 (33%)
  - 박성용 (성용): 12건 (33%)
  - 기타: 12건 (33%)

→ QA팀에 67%의 업무가 집중되어 있음
```

### 1.2 구체적 오류 사례
| QMS 직무 | 현재 배정 | 문제점 | 올바른 배정 후보 |
|---------|----------|--------|----------------|
| SW 위험관리 | RA/QA 이선희 | SW 전문성 필요 | SW R&D 양선호 |
| HW 위험관리 | RA/QA 박성용 | HW 전문성 필요 | 로보틱스 방정배 |
| 납품(SW) | RA/QA 왕인영 | SW 배포 업무 | SW R&D |

### 1.3 근본 원인
1. **추측 기반 판단**: AI가 직함만 보고 "QA니까 품질 관련은 다 QA" 식으로 추측
2. **실제 업무 정보 부족**: 누가 실제로 무슨 일을 하는지 모름
3. **JD 데이터 미활용**: 829개의 상세 직무 데이터가 있으나 사용 안 함

## 2. JD 데이터 구조 분석

### 2.1 "전사 JD 종합.xlsx" 시트 구조
```
[전체 직무기술서 종합] 829행
  - 순번, 대분류, 중분류, 소분류, 세분류
  - 능력단위명칭, 능력단위요소 (실제 업무 내용)
  - 업무수준, 업무연계(담당자), 시기, 중점현안

[참고 1. 직무 사전] 16,386행
  - 상세 직무 정의 및 수행준거

[업무수준 분류] 31행
  - 업무 난이도 정의
```

### 2.2 핵심 발견: "업무연계" 컬럼
담당자별 JD 업무 현황:
```
- 방정배: 38건 (로봇/HW 업무)
- 정누리현: 50건 (연구개발/임상 업무)
- 정수현/정한뉘현: 32건 (경영기획 업무)
- 연구원: 30건 (SW R&D 업무)
- 왕인영: 12건 (총무/행정 업무)
- BLT: 18건 (특허/법무 업무)
- 이수민: 6건+ (RA/임상 업무)
```

→ **실제 담당자 정보가 JD에 명시되어 있음!**

## 3. 개선 방향

### 3.1 핵심 전략: "추측"에서 "사실 기반 매칭"으로

| 구분 | 기존 (As-Is) | 개선 (To-Be) |
|------|-------------|--------------|
| 데이터 | 팀명 + 1줄 역할 | JD 829개 업무 + 상세 내용 |
| 판단 | "QA니까 품질 담당" | "JD에서 이 업무 담당자가 누구지?" |
| 결과 | 팀장 위주 배정 | 실무자(JD 담당자) 배정 |
| 이유 | "적합해 보임" | "JD상 X 업무를 담당 중이므로" |

### 3.2 3단계 로직

```
Step 1: JD 프로필 구축
  - 사람별로 담당 업무 목록 생성
  - 예: {"방정배": "로봇 설계, 가속기 제어, 모션 제어..."}

Step 2: QMS-JD 매칭
  - QMS 업무와 유사한 JD 업무 검색
  - 해당 JD 담당자를 1차 후보로 추출

Step 3: AI 최종 판단
  - JD 후보 정보를 프롬프트에 포함
  - AI가 사실 기반으로 최종 결정
```

## 5. 예상 개선 효과

### 5.1 배정 정확도 향상
| 업무 | 기존 배정 | 개선 배정 |
|-----|----------|----------|
| SW 위험관리 | RA/QA 이선희 | SW R&D 양선호 |
| HW 위험관리 | RA/QA 박성용 | 로보틱스 방정배 |
| 납품(SW) | RA/QA | SW R&D |
| 설계검증(HW) | QA | 로보틱스 |

### 5.2 균형 있는 업무 분배
```
기존: QA팀 67% 집중
개선 예상:
  - RA/QA: 30-35% (품질 고유 업무)
  - 로보틱스: 20-25% (HW 관련)
  - SW R&D: 20-25% (SW 관련)
  - 경영기획: 10-15% (경영/행정)
  - 기타: 5-10%
```

```
기존: "품질 시스템 운영과 밀접하게 관련..."
개선: "JD에서 '로봇 설계 및 HW 검증' 업무를 담당 중이므로, HW 위험관리에 적합함"
```
